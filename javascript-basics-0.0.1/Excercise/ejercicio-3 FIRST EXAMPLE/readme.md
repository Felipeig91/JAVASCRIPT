JavaScript Basics

Welcome to the JavaScript Basics repository. This project is designed to help you learn the fundamental concepts of JavaScript through practical examples and exercises.

Getting Started

To get started with these exercises, ensure you have [Node.js](https://nodejs.org/) installed on your machine.

Topics Covered

- Variables and Data Types
- Functions and Scope
- Control Flow (If/Else, Loops)
- Arrays and Objects
- Asynchronous JavaScript (Promises, Async/Await)
