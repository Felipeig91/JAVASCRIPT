# JavaScript Moderno: Guía para dominar el lenguaje 🚀

Este repositorio contiene mis notas, ejercicios y proyectos desarrollados durante el curso de **Fernando Herrera** en Udemy. El objetivo es profundizar en el estándar actual de JavaScript (ESNext) y herramientas modernas de desarrollo.

## 📚 Contenido del Curso

El curso cubre desde las bases hasta conceptos avanzados, incluyendo:

* **Fundamentos Avanzados:** Uso de clases, propiedades privadas y prototipos.
* **Entorno de Desarrollo:** Configuración de **Vite**, manejo de **NPM** y **Node.js**.
* **Web Toolkit:** Implementación de **Hot Reload**, manejo del DOM y eventos.
* **Persistencia y APIs:** Operaciones **CRUD**, Fetch API y carga de archivos.
* **Patrones y Buenas Prácticas:** Estructuración de código modular y limpio.

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** JavaScript (ES6+)
* **Bundler:** [Vite](https://vitejs.dev/)
* **Gestor de paquetes:** NPM
* **Entorno:** Node.js

## 📂 Estructura de Proyectos

A continuación, los proyectos destacados desarrollados en este curso:

1.  **Blackjack:** Juego interactivo para aplicar lógica y manipulación del DOM.
2.  **Todo App:** Aplicación de lista de tareas con persistencia en LocalStorage.
3.  **HTTP & CRUD:** Prácticas de peticiones a servicios externos y manipulación de datos.
